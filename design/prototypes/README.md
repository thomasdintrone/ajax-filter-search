# Design prototypes (2.3.0)

Static HTML for design review, not production code. `editorial.html` is the Editorial Grid and `library.html` the Resource Library (working names). Add `#dark` to the address for the dark theme. `node design/prototypes/render.mjs` writes the desktop and mobile PNGs here (they are ignored by git). The folder is excluded from release packages with the rest of `design/`.
